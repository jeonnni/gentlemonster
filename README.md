# 프로젝트명
> 젠틀몬스터 웹사이트 리뉴얼

# 개요
> 이 프로젝트는 부트스트랩(Bootstrap), CSS, HTML을 활용하여 젠틀몬스터 공식 웹사이트를 리뉴얼한 개인 프로젝트입니다.
> 기존 사이트를 분석하고, 현대적인 웹 표준과 디자인 트렌드를 반영하여 사용자 경험(UX)과 사용자 인터페이스(UI)를 개선하는 것을 목표로 했습니다.

# 주요 내용
1. 반응형 디자인 구현: 부트스트랩 그리드 시스템을 활용해 다양한 디바이스(PC, 태블릿, 모바일) 환경에 최적화된 레이아웃 구축
2. UI/UX 개선: 최신 디자인 트렌드를 반영하여 시각적으로 세련된 인터페이스와 직관적인 사용자 경험 제공
3. 웹 접근성 강화: 사용자 편의를 고려한 폼 요소 및 내비게이션 개선

# 프로젝트 목표
> 웹 표준에 부합하는 구조와 스타일을 통해 보다 향상된 웹 서비스를 구현
